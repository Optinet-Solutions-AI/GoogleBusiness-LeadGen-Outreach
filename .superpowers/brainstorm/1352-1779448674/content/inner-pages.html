Inner-page workflow pattern

The home tells the operator "go here". The inner pages must tell them "do this." One unified pattern across lead detail, batch detail, and the list pages.

The pattern

Every detail page gets a workflow header on top, then content below. The header has 4 things:

  1. Breadcrumb back to where they came from
  2. Stage indicator — visual chain of pipeline stages, with "you are here" highlighted
  3. ONE primary action — the next step computed from the current stage (giant button)
  4. Secondary actions — overflow dropdown for less-common operations

List pages (Replies, Leads) get a row-level mini version: the same primary action as a button on each row, so operators can act without opening detail.
