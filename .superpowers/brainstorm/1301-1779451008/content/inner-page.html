How it works

The dark "NEXT STEP" pill at the top changes based on lead.stage. Each stage has one primary action and one or two alternatives. Same component renders on every lead — no operator memory required.

Per-stage next-step copy

  • needs_email → "Add an email address" + Skip lead
  • outreached → (no action — passive wait) + Resend / Bump
  • replied → "Triage the reply" — Meeting booked / Not interested / Hot but later
  • meeting_booked → "Mark meeting done" + Reschedule
  • meeting_done → "Improve the site for them" + Mark closed-lost
  • improved → "Hand over the domain" + Schedule follow-up
  • handed_over → "Mark closed-won" — sends first invoice + adds MRR
