Short, non-technical guides for running and understanding this app. If you're not a developer, **start here**.

## Where the deeper docs live (for developers)
- `docs/architecture.md`, `docs/data_model.md`, `docs/stage_specs.md`, `docs/deployment.md` — how it's built.
- `docs/superpowers/specs/` — the **design docs** (the "what + why" we agreed before building each thing).
- `docs/superpowers/plans/` — the **build plans** (step-by-step task lists used to implement).
- `docs/decisions/` — one-off decision records.
- `docs/status/` — weekly/daily progress log.

## Our rule
Every new feature or flow gets a short plain-language note in `docs/guides/` **and** a design doc in `docs/superpowers/specs/`. Keep the guides simple — that's their whole job.
