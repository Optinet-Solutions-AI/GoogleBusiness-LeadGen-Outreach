# What this app does (plain overview)

It finds local businesses, sorts them by what they need, builds a demo website for the good
prospects, and helps you **reach out** (email / SMS / DM) to turn them into paying clients.
Everything is organized so you're never guessing what to do next.

> Looking for the full step-by-step runbook? See the **[User Manual](user-manual.md)** (also
> live in-app at **/manual**).

## The big flow
1. **Scrape** businesses from Google Maps (a "batch").
2. The app **sorts each lead** into one of three groups (we call them *segments*):
   - **No website** → pitch building one.
   - **Old / weak website** → pitch improving it.
   - **Good website** → a different, lighter pitch.
3. **Build** a personalized demo site for the lead, automatically (AI copy + a niche template,
   deployed to a live URL).
4. **Reach out** with the demo link — email, a texted form link (SMS), or a manual DM.
5. Replies and form submissions land in the **Inbox** for follow-up; you book a meeting, swap in
   the customer's real content, point their domain at the site, and close.

## The left menu, page by page
| Page | What it's for |
|------|---------------|
| **Today** | Your at-a-glance home: what needs attention + the key numbers. |
| **Analytics** | The "are we winning?" view — funnel, conversion, and **cost per finished lead**. |
| **Status** | Plain-English activity summary by week / month / year. |
| **Batches** | The raw scrapes — where leads come from. |
| **Leads** | Every lead, searchable/filterable. |
| **Campaigns** | Bulk outreach jobs. Make one, then watch contacted / interested / success rate. |
| **Inbox** | People to follow up with (email replies + form submissions). |
| **Email** | Connect and test your sending mailboxes; watch warm-up. |
| **Social** | The manual-DM worklist for Facebook/Instagram leads. |

## What's live vs. coming
- **Live now:** scraping → segmenting → building demo sites → email outreach (incl. the
  screenshot-first sequence) → reply sync + inbox → analytics. SMS and assisted DM are wired and
  ready as their providers come online.
- **Note:** in-app **voice calling was removed** — that work moved to a separate app. This
  dashboard is email / SMS / DM only.
