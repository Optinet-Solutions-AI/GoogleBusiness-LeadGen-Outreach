# Glossary (plain English)

The words we use, without the jargon.

- **Lead** — a business we might call (name, phone, city, website status).
- **Batch** — one scrape of Google Maps (e.g. "plumbers in Austin"). Where leads come from.
- **Segment** — the group a lead falls into, which decides the pitch:
  - *No website* → offer to build one.
  - *Old website* → offer to improve it.
  - *Good website* → a "what do you need?" chat.
- **Campaign** — a calling job: a list of leads + a schedule. You make one, then work its call list.
- **Assistant** — the AI agent on Vapi that does the talking. Ours is nicknamed **"john."** It has a **prompt** + a **voice**.
- **Prompt (system prompt)** — the agent's instructions: who it is, what to say, how to talk. Editing this changes its behavior.
- **Voice** — how the agent sounds (from your 11labs voices, e.g. "Stephen," "Mark," or a custom one).
- **Test call** — talking to the agent **in your browser** (mic, live transcript). Free, no phone number, calls no one. Just for tuning.
- **Save** (Agent page) — saves your edited prompt + voice to the **test** agent.
- **Reset to recommended** — undo a bad edit; restores our last good prompt.
- **Production** — the "real" setup that calls actual customers. We keep testing separate so a bad experiment can't break it.
- **Promote / publish** — taking a good, tested version and making it the live (production) one. (Not built yet — testing only for now.)
- **Vapi** — the platform that runs the voice agents (your "Voize" sits on top of it). One account holds all the assistants + voices.
- **11labs (ElevenLabs)** — the service that provides the voices.
- **Mobivate** — the SMS service we'll use later to text the one-time link.
- **Contacted / Interested / Success rate** (Campaigns) — how many leads were dialed, how many were interested, and interested ÷ contacted.
- **Inbox** — the follow-up queue: interested calls + replies.
